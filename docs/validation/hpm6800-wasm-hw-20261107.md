# HPM6800EVK 的 OpenOCD Wasm RAM 真机验收

2026-11-07（北京时间）。源码基线为 `ee00aa3cce6ba02cdba4e12a360eba2dc0d34b3c` 加工作区改动。验证对象是 localhost 源码工作台、Chrome 156.0.8078.48、akaLinkPro（CMSIS-DAP v2 FW 2.1.2）和 HPM6800EVK。浏览器加载全量 Flash 驱动的 OpenOCD `9f2d8762b3a75b4d7b2155affcf3d8bb8eb8849a` Wasm，下载写入限定在 ILM。没有启动本机 OpenOCD，没有执行复位或 Flash 编程，也没有做 Flash 全盘回读。按用户要求，直接下载 RAM ELF，不备份或恢复原运行现场。 [机器证据](hpm6800-wasm-hw-20261107.json)

| 步骤 | 真机结果 |
|---|---|
| 原版 CFG | 通过 `toolbox.py` 上传 SDK 1.11.0 的 `boards/openocd` 目录并选择 `hpm6800_all_in_one.cfg`；Worker 校验 7 份原文件后执行配置。 |
| 连接 | WebUSB 枚举并打开 CMSIS-DAP v2；JTAG 8 MHz，实测 TAP `0x1000563d`，`hpm6880.cpu0`，XLEN 32，`misa=0x4094112d`。 |
| 下载到 RAM | 页面一键下载 ELF，唯一加载段为 ILM `[0x00018000, 0x00018014)`；通过同一 Wasm 会话另行读回 20 字节一致。 |
| 运行到 `main` | PC `0x00018008`，`hpm6800_ram.S:14`，`a0=0`。 |
| 两次 F10 | PC `0x0001800C` 和 `0x00018010`，分别停在第 16、18 行，`a0=1、2`。 |
| 结束 | CLI 确认调试会话已断开并释放协调锁。未运行原固件恢复流程。 |

首次授权要由用户在 Chrome 中点击「连接」并选择探针，CLI 不能替代这次手势。授权后，从导入 CFG 到下载、单步和断开均可使用工作台 CLI。旧版 Wasm 在 `init` 超时：只移除 CMSIS-DAP 空读仍复现；再将 libusb 的 `Atomics.waitAsync` 换成 Worker 事件唤醒后，完成真实收发。随后首次暂停取寄存器遇到 OpenOCD 把 RV32 的 `x8/s0` 命名为 `fp`，在任何 RAM 下载前恢复运行并断开；补齐别名映射后完整复测通过。 [链接适配](../../web/tools/dev/link-openocd-core-wasm.py) · [寄存器映射](../../web/app/dbg/openocd-session.js)

复测时，先用 `toolbox.py --runtime <运行时目录> page dbg describe` 核对控件，选择 `openocd` 后端并上传原版 SDK 配置目录及 `web/tools/selftest/fixtures/dbg-cfg` 源码目录。待确认探针和板卡空闲后连接。下面的脚本校验入口、唯一加载段和固定指令，直接覆盖该段 ILM，并在最后断开。ELF 可按[原 JTAG 验收的编译命令](hpm6800-cfg-hw-20261107.md#复现)在独立目录重建：

```powershell
python -X utf8 web/tools/selftest/dbg-hpm6800-wasm-hw.py <运行时目录> <hpm6800_ram.elf> <新证据目录>
```

重建本次浏览器会话版时，按[原体积对比](openocd-core-wasm-size-20261107.md)准备固定的 OpenOCD、Jim Tcl、libusb 1.0.30 及 Emscripten 4.0.10。在全量版链接命令上加 `--browser-session --libusb-source <libusb 源码> --libusb-build <配置过的 libusb 构建目录>`；产物与独立配置阶段原型不同。本轮未验证冻结 Windows 包或线上环境，也没有扩大已验收的板卡范围。

软件验证覆盖调试核心、RAM/CFG、后端切换、探针互斥和 CLI，Web 合并包及 CLI 生成清单一致性通过。从仓库根目录通配执行所有 Web 脚本会同时选中需要 `web/` 工作目录、隔离 CDP 或外部固件样例的用例，不作为全量通过证据。已按正确工作目录复跑相关离线用例；浏览器路径以本报告记录的 CLI 真机结果为准。
