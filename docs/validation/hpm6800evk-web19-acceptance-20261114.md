# HPM6800EVK 的 web.19 回归验收

2026-11-14（北京时间）。固定安装 `1.1.0-web.19`（源码 `7ec5bbb`，发布 `8d2ccc9`），隔离 Chrome 145 复用既有 USB、HID、COM34 权限，设备选择器调用 0。akaLinkPro 使用 web.19 Release 的探针 APP（SHA-256 `cd708c27b5ff9effd621cb17b4fea9d51dde8fe71d05684dd43137d3d25b7ff0`）。目标 TAP `0x1000563d`、RV32。CMSIS-DAP 请求 8 MHz，探针内部 DMI idle 8，未外测物理 TCK。

## 已通过

- SDK 1.11.0 原版 CFG 目录导入和顶栏连接。调试脚本 13/13，含源码和指令步进、40/40 停走、断点重命中、两种软件复位、XIP 常量和监视，探针重连与异常计数均为零。
- ILM `0x18000`、非缓存 AXI `0x1260000`，运行和暂停态 64 B、20 KiB、64 KiB 写入与独立读回均一致。探针内部 SBA 同地址 1 KiB × 50，三轮读 1,549,068–1,550,289 B/s，写 1,562,345–1,563,120 B/s，SBA sticky 与整块重试为 0，写入校验和一致。运行态 64 KiB 的浏览器脚本墙钟最高读 117,810、写 109,191 B/s，包含 Python/浏览器消息及数组转换。
- 官方 CFG 烧录 RTT flood ELF 46,712 B 和 Scope ELF 47,856 B，各 13 扇区、校验及复位通过。测试范围限 XPI 前 64 KiB。最终恢复原 16 扇区，两次独立回读 SHA-256 均为 `a0f998fdfa7d3cde6bc2439fb46ab5a0d5f11a2258b50ec63211d3c0c92ca0db`，与开测双读一致。ILM、AXI 两段各 64 KiB 均写回原内容并读回核对。
- RTT Viewer 用同一 flood ELF，Web 两轮 0.177–0.179 MB/s，固定工作台 CLI 驱动同一 Chrome Viewer 两轮 0.172–0.176 MB/s。约 8 秒稳态窗，原始字节逐字节与负载相符，覆盖、错位计数为 0。CLI 数字含工作台结果返回时间。
- RTT 转发使用两组不同的 15,744 B 非重复 AXI 环。浏览器每轮实收、探针 `moved` 和目标读指针均为 15,744，读写错误均为 0。STOP 后按钮可再次启动，COM34 保持打开且回到 UART，临时 SRAM 原值恢复。

## J-Scope

Scope ELF 采用非缓存 AXI 上的 `g_v`，FAST_BATCH 与 CDC_OFF 均开启。以下每轮约 10 秒，Web 原始 512 B 包逐帧核对 DEF、格式化字节、包序、STOP 生成与实收。原生 CLI 使用 EP `0x83` 的有序 libusb 预读及 ZLP 收尾。六轮均无 USB 丢样、读错、无效样本、包序缺口或停采尾差。

## 连续 RTT 转发未通过

同一 flood ELF 上，web.19 APP 的浏览器三轮约 8 秒均实收 0 B，每轮 86 次读错。原生 CLI 的 60 秒轮同样实收 0 B、605 次读错。两端均出现探针已找到控制块但无持续交付。换仓库旧目录的 flood ELF，XPI 有效镜像读回相同，现版 APP 只收了起始 32,774 B，随后 8 秒 0 B。把探针 APP 临时回退到此前验证的 192,848 B 版本（SHA-256 `e0e0f3e74c1bdb19bb7b30db3b9b7cc97f03a185abfe690d8dbd6d694018f0ac`），固定 Web、相同板和相同 ELF 下原生也只收相同 32,774 B，随后 8 秒 0 B。两份起始数据的 SHA-256 相同。比较说明当前现场停流可跨 APP 版本复现，归因待定位。

停流后 OpenOCD 一度报 hart 无法暂停、`dmstatus=0x00400ca2`，用 SDK OpenOCD 直接经 DMI 发系统复位，释放后 `dmcontrol=0x1`、`dmstatus=0x004c0ca2`，随后可重新建链。探针最后恢复同一个 web.19 APP，DFU 读回一致并按同序列号回到运行态。

最后一次恢复完成后，独立调试会话确认原应用的 XIP PC，心跳从 359,336 增至 361,455。目标继续运行，探针占用、等待和失败列表为空。

本板 JTAG 座未接目标 NRST。外接 SPI/I²C/ADC/SWO/ETM、系统文件选择器、真实 UART 回环与早期历史的完整排列矩阵本轮未执行。原始证据在 `tmp/hpm6800-web19-20261114/`。问题见 ISSUE-149、150。
