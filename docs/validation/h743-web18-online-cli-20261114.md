## 线上 H743 功能

- Chrome 145 直接加载公开 Pages，用隔离配置复用既有 WebUSB、WebHID 与 Web Serial 授权。设备选择器调用为 0。只使用 akaLinkPro CMSIS-DAP FW 0.1，序列号 `B4444F2110DDDAFE44800BBB0AE800E0`，CDC 为 COM34。
- AP2 读到芯片 ID `0x20036450` 和初始 `DBGMCU_CR=0`。官方 H7 CFG 成功检查 Cortex-M7，CPUID `0x411fc271`，SWD DPIDR `0x6ba02477`。本轮初态为 Flash 运行、MPU 关闭。
- 线上烧录页用原版 CFG 在 10 MHz 写入并校验 1,192 B RTT ELF 和 1,240 B J-Scope ELF。测试完成后写回原首扇区并复位。烧前与恢复后各两次独立读取完整 2 MiB，四份 SHA-256 均为 `7b6a4f9e7b83de0b9cf81236fe38508b5bcd519b7dc85fd9b811befdb77e666b`。NRST 实测运行计数由 2,210 ms 回到 727 ms，目标继续以 480 MHz 运行，CFSR/HFSR 均为零。
- 调试页完成暂停、指令单步（PC `0x080002a0` → `0x080002a2`）、继续、32 B SRAM 写入读回和原值恢复。RTT Viewer 下行 19 B 由目标缓冲和写指针独立核对。
- 从正在运行的 Viewer 顶栏切到 RTT 转发，60 MHz 转发约 10 秒后从 J-Scope 顶栏接管。COM34 保持打开并回到 UART。J-Scope 在同一 RTT 固件上采集 `g_loops` 和 `g_ms`，收到 301,448 组，约 100 k 组/s，探针跳拍 12 组，USB 丢样、包序缺口和停采尾差为 0。最终占用、等待和失败列表均为空。

## 同板测速

RTT 使用同一 480 MHz／HCLK 240 MHz ELF、AXI SRAM RTT 控制块 `0x24000014` 和连续 `hello world!\n` 上行负载，预热后测约 8 秒。MB/s 为十进制。Viewer 使用回报的 SWD 速率，转发取探针状态、J-Scope 取原始 DEF 的 SWD 速率。

- Viewer 使用 `stm32h7` 配置和发布包的 OpenOCD Wasm。CLI 通过固定安装版的工作台队列驱动本机 Chrome 页面，USB 仍走 WebUSB。页面自动暂停高速文本渲染，接收和记录继续。六个测速窗的覆盖及错位计数为 0。原生 Node/WinUSB 试验复现 ISSUE-106 的描述符错误。临时先占用接口后能读描述符，但 CMSIS-DAP 读写出现 `Resource busy` 与回包错序，没有取得有效的原生 Viewer 速率。
- RTT 转发的 CLI 使用 HID 控制和 pyserial 原生接收 COM34。六个稳态窗口独立对齐 13 B 周期后逐字节一致。各轮完整保存字节数与探针 STOP 的 `moved` 相等，读写错、重新扫描和接收异常均为 0。首轮原始流含启动横幅。重复文本无法检出整周期遗漏，前次候选已用 15,744 B 非重复载荷核对原始数据、探针计数和目标读指针。[前次非重复载荷验收](h743-web18-e2e-20261114.md#rtt)
- J-Scope 使用同一专用 ELF 和 AXI SRAM 变量，FAST_BATCH 与 CDC_OFF 均开启。单路为 `g_pack.u_hi`，八路为 `g_pack` 的八个字段。CLI 以 libusb 原生异步读取 EP `0x83`，保留有序交付、STOP 短包/ZLP 和 action 13 收尾。速率由暖机后约 8 秒的探针 24 MHz 时间戳与生成计数计算，逐轮另解析完整原始数据，核对 DEF、包序、格式化字节和最终生成计数。八轮的 USB 丢样、读取错误、无效样本、包序缺口和停采尾差均为 0。500 kSa/s 档的稳态跳拍为 Web 60,824 组、CLI 59,928 组，约占请求的 1.5%。

## 轨迹和现场范围

- 线上 SWO 能识别 H743 和读取时钟配置，实际收数与起点清理沿 ISSUE-144 跟踪。ETM 在线上能连接本机桥，读取能力和记录列表，并从顶栏识别实板 ETMv4、读取 RCC 和释放探针。Chrome 145 默认阻止隔离配置访问回环，页面误报找不到桥。验收在该测试配置中为 Pages 来源临时授予 `loopback-network` 权限后通过，未修改用户浏览器配置。KingstVIS 的 23367 端口未监听，本轮没有新 ETM 波形。[Chromium 回环权限](https://chromium.googlesource.com/chromium/src/+/c4e715d856ad11559bd8c41c1ba2914cbb0785b3%5E%21/)
