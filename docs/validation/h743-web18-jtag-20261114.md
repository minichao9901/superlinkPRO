# H743 ARM/JTAG 真机复验

2026-11-14（北京时间）。线上 GitHub Pages 与固定 Windows 工作台均为 `1.1.0-web.18`，发布提交 `3f8bec3`。使用 STM32H743、akaLinkPro FW 0.1，探针序列号 `B4444F2110DDDAFE44800BBB0AE800E0`。断电重启后重新按序列号匹配 USB 与 HID，另一只同 VID/PID 的探针未参与。Chrome 145 的测试配置复用原授权，设备选择器调用为零。

## 线上入口与诊断范围

公开页面用 `transport select jtag`、CMSIS-DAP 和原版 STM32H7 双 bank CFG 导入，在连接目标前被拒绝。错误为「CFG 没有 Cortex-M / SWD 或 RISC-V / JTAG 核」。将同一 CFG 直接交给线上原版 Wasm，真实扫到 ARM DAP TAP `0x6ba00477`、STM32 边界扫描 TAP `0x06450041`，读到 Cortex-M7 CPUID `0x411fc271`、AP2 芯片 ID `0x20036450` 和目标 RTT 控制块。发布版的 Cortex-M 建链随后仍会尝试用 SWD DPIDR 命令确认，导致打开失败。

以下 Web／工作台 CLI 验收使用隔离页面临时载入官方 CFG，并在该页把建链的 SWD DPIDR 验证替换为核对实时 `scan_chain` 返回的两个 TAP。HID 将同一探针临时切到 SWD + JTAG，结束后逐字节恢复原配置。烧录、调试、RTT 轮询均用发布版代码和原版 Wasm。线上发布版和固定安装包的默认页面入口仍会复现导入限制。

## 烧录、调试和恢复

- JTAG 10 MHz 请求档，用公开页面的烧录按钮将板上同一个 1,192 B RTT ELF 写入、校验并复位。烧录前后各独立读两份完整 2 MiB Flash，四份 SHA-256 一致，为 `7b6a4f9e7b83de0b9cf81236fe38508b5bcd519b7dc85fd9b811befdb77e666b`。
- 顶栏 NRST 后运行计数从 2,768 ms 回到 1,136 ms。暂停、单步、继续通过，PC 从 `0x080002b0` 到 `0x080002b2`。临时写入 32 B SRAM，读回正确并恢复原值。目标以 480 MHz 运行，Flash 独立读回时 CFSR/HFSR 为零。
- J-Scope 和探针 RTT→CDC 目前只有 ARM/SWD 与 RISC-V/JTAG 两种后端。网页下拉、HID `0x31` action 10 及采样器 `0x32` 均未提供 ARM/JTAG。两项没有 ARM/JTAG 速度数据，也无法复跑上一轮的转发到 J-Scope 热切换。SWO 和 ETM 页面使用默认 SWD 目标连接，本轮未计入 JTAG 验收。

## RTT Viewer 速度

使用 480 MHz／HCLK 240 MHz 原应用，控制块 `0x24000014`，连续 `hello world!\n` 上行，预热后约 8 秒，MB/s 为十进制。表中是 CMSIS-DAP / OpenOCD 的请求档。固件中的 JTAG 序列与 DP 读写采用各自时序实现，本轮未用外部仪器测量物理 TCK。

| JTAG 请求档 | 线上 Web Viewer | 固定安装工作台 CLI | Windows 原生 OpenOCD CLI |
| --- | ---: | ---: | ---: |
| 10 MHz | 0.151 MB/s | 0.140 MB/s | 0.222 MB/s |
| 25 MHz | 0.143 MB/s | 0.138 MB/s | 0.238 MB/s |
| 45 MHz | 0.142 MB/s | 0.137 MB/s | 0.247 MB/s |
| 60 MHz，两轮 | 0.148／0.138 MB/s | 0.125／0.122 MB/s | 0.242／0.247 MB/s |

工作台 CLI 经 Chrome WebUSB 执行相同 Viewer；十个窗口均报告覆盖、错位为零。原生 OpenOCD `cb0c224` 使用同一探针 USB Bulk、同一官方 CFG 和其自带的 RTT TCP 服务，轮询间隔设为 1 ms。五份原始窗口按周期对齐后逐字节一致。原生日志均确认目标两个 TAP、Cortex-M7 和探针序列号。重复载荷可验证字节错位，整周期遗漏仍需序号负载核对。此前同板 SWD 结果见[线上 SWD 对照](h743-web18-online-cli-20261114.md#同板测速)。

Web Viewer 另开一轮，清空缓冲后保存 844,534 B 上行并逐字节对账。从页面发送 18 B 下行标记，独立读回目标缓冲及写指针，随后恢复缓冲原值。最后确认探针配置逐字节恢复，浏览器占用、等待和失败列表为空。

本机原始文件、前后 Flash 备份、日志及试验脚本位于 `tmp/h743-online-jtag-20261114/`。问题见 ISSUE-058、147 和 148。
