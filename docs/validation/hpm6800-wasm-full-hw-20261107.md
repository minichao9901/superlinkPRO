# HPM6800EVK 的 Wasm 与探针高速链路真机验收

2026-11-07（北京时间）。使用本地 8911 工作台、akaLinkPro 和 HPM6800EVK。源码基线为 `73e4b82` 加 Wasm 迁移工作区变更。调试使用 HPM SDK 1.11.0 原版 `hpm6800_all_in_one.cfg`，8 MHz JTAG。烧录器和 RTT Viewer 使用各自页面生成的 HPM6800EVK Wasm 配置。探针 TAP ID 为 `0x1000563d`。硬件控制经工作台 CLI，CDC 性能窗口由主机直接读取 COM33。 [机器证据](hpm6800-wasm-full-hw-20261107.json)

| 验收项 | 真机结果 |
|---|---|
| Wasm 调试压力 | 同一会话 13/13，含 19 步指令单步、19 步源码跳过、源码进出、复位和变量检查。源码步进后 40/40 轮停走，OpenOCD 断点列表与页面对账一致，清空后无残留。异常计数、页面错误及重连次数均为 0。 |
| 烧录页 | Echo flood 镜像 47,128 B，scope 镜像 47,856 B，均覆盖 13 个扇区。开启逐扇区读回及复位，首轮约 8.95 s 和 10.21 s，复位后分别以 RTT 回显和采样计数确认应用运行。 |
| SRAM | 4、16、64 KiB 各两遍逐字节校验。CPU 暂停时扫过 8、10、20、25 MHz，峰值读 33,207 B/s（8 MHz）、写 35,545 B/s（10 MHz）。CPU 运行时用原版 8 MHz CFG 复测，峰值读 13,456 B/s、写 138,469 B/s。计时包含工作台 CLI 的调度和传输。测试区域 `0x18000` 起 64 KiB 位于 dbgstress 的加载段之外，各档结束后原内容读回一致。 |
