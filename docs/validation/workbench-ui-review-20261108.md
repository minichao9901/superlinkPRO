# 工作台界面审阅

在本地工作台的独立浏览器页逐页查看 15 个入口，视口为 1280 × 720。使用模拟探针和未授权串口状态观察提示，不连接设备。源码入口逐页切换并检查侧栏，合并入口复核 RTT 选项、转发备注和烧录器芯片标签。

| 页面 | 审阅结果 |
| --- | --- |
| 串口助手、RTT 转发、SPI 转发 | 端口下拉只显示「未授权串口」，授权操作放在下一行提示。修复共享状态更新丢失 `hint` 样式的问题，备注保持 12.5 px，连接成功、警告和错误各保留状态颜色。 |
| 终端 | 相邻的两段说明合并到一个「使用说明」。终端输出和快捷键说明各有固定位置。 |
| RTT Viewer、J-Scope 波形、调试器 | 目标接口使用 `SWD / ARM`、`RISC-V / JTAG` 两种短名称。波形页把数据端点未连接的状态与模拟设置分开。调试器的会话、断点、栈帧保持现有分区。 |
| 烧录器 | HPM 选项保留实际型号和 RISC-V 架构，去掉「零安装」。默认时钟用短名称，详细档位留在提示中。 |
| USB→SPI/QSPI、SPI/QSPI 屏幕 | 侧栏使用「并发读取」「USB 批量」等可对照 USB 请求的术语。命令表及图案控件仍留在数据工作区。 |
| SWO、ETM | SWO 的空状态说明降低到提示层级。ETM 等待页的链接使用统一主题色，内嵌工作台能正常载入。 |
| USB→I2C、USB→ADC/DAC、工程下载 | 检查了地址矩阵、示波器和下载卡片的默认状态。没有发现需要本轮改动的横向溢出或截断。 |

15 页均能激活，页面及侧栏没有横向溢出。源码和合并包都验证了简化选项及备注字号。Flash、RTT 生命周期和会话配置的现有回归通过。
