# SuperLinkPRO 可执行手册验收

2026-11-12 在本机工作台的真实 Chromium 页面逐条点验 [CLI 入门手册](../../toolbox-cli-first-run.md)。手册的 13 条命令分别显示输出、退出码及日志位置。源码运行时与桌面 EXE 使用同一份 Markdown 和固定 CLI 操作，便携版通过包内 CLI 执行。

本轮按用户选择执行软件与冻结 EXE 验收。浏览器保持真实页面、鉴权队列、CLI 子进程、ELF 解析、烧录器和扇区读回校验流程。WebUSB 授权和探针端的命令响应由软件模型提供。

| 场景 | 浏览器结果 |
| --- | --- |
| 启动、连通、查看目标选项与授权 | 复用运行中的工作台，CLI 就绪，内置目标选项可查询。授权按钮收到模型设备。 |
| STM32H7 | 使用原 H743 `fw.elf`，预览与模拟烧录均为 61,208 字节，DEV_ID 为 `0x450`。模型记录 1 次擦除、1 次写入、2 次读取和 1 次软件复位。 |
| HPM6800EVK | 使用仓库里的 Scope ELF，预览与模拟烧录均为 47,856 字节，JTAG TAP 为 `0x1000563d`。模型记录 1 次擦除、1 次写入、2 次读取和 1 次软件复位。 |
| 结果与日志 | 两条流程的页面均显示读回校验通过，原 CLI job 查询为 done。 |

原始浏览器输出及截图在本机 `tmp/command-manual-acceptance-20261112/`。记录对应 ISSUE-138。

首个冻结候选的 HTTP 验收发现，服务在首页注入手册标记使响应字节与包清单不一致。入口探测改用鉴权状态接口，首页以清单校验的原始字节返回。
