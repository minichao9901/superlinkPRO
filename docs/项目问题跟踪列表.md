## 维护规则

- **每次遇到问题都要登记或更新已有条目，修复与问题状态更新放在同一提交。** 工作指引见 [AGENTS.md](../AGENTS.md)。
- ID 使用 `ISSUE-NNN`，新增递增、不复用。复现条件相同则更新原 ID；发现不同根因再拆分。
- 优先级：P0＝阻断/严重破坏；P1＝数据正确性、任务互斥、重要验收阻断；P2＝功能、性能、交付；P3＝说明或低影响体验。
- 状态：**待处理**（当前证据已确认）、**待复核**（历史报告/疑点，尚无本次重现或最新关闭证据）、**待验收**（缺指定验收证据）、**处理中**、**已规避**（有临时办法，原因未消除）、**已解决**（有对应修复/验收证据）、**不成立**（有反证）。
- “已解决”沿用所链接报告的日期与范围，不代表所有型号/所有场景重新验收。旧报告不能单独证明缺陷在当前版本仍存在。
- 处理人默认未分配；接手时在原条目的行动栏登记 session/负责人及进展。状态变更更新日期，并追加底部变更记录。
- 问题关闭须保存：原因、修复提交/变更、验证命令或报告、验证范围。环境/浏览器限制与产品代码 Bug 分开说明。
