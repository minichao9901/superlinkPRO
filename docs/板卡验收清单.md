# SuperLinkPRO 最小板卡验收

七组各五项，共 35 个用例定义（实例 ID `S01`…`E05`），保留全部性能项。整板验收按下表展开，定向修改复测受影响的入口。开测前记下探针序列号、APP、工作台版本、目标 ELF、接线和备份范围。每项记录链路、时钟和来源、结果、计数及证据。报告用「通过／失败／阻塞／待验／人工取证／不支持／不适用」标明实际结果，历史实测与本轮结果分开。 [详细用例](板卡验收用例参考.md) · [CLI 指南](toolbox-cli-ai.md)

## 性能与摸高条件

R01 的 H743、HPM6800EVK 序号主窗为 Web 与原生各 60 秒，另跑一次同页短窗。F103ZE 沿用既有序号夹具的 8 秒窗。合并三个窗口核对跨边界序号，加查两条路径的 STOP 计数和目标 `RdOff`。R02 用同板固定文本夹具测 8 秒吞吐，可和 R01 分别取证，再一起离线复核。

J03、J04 从上次通过的周期起步，只试相邻档。每条工作台链路分别给单路和八路做 **60 秒 Web 稳定窗**和 **60 秒原生固定窗**。ARM/JTAG 的单路和八路各做一个原生 60 秒窗口。原生固定点从 SuperLinkPRO 同板同链路的历史实测选取，首验在短窗找稳定点。稳定窗要求探针跳拍率 **<0.1%**，USB 丢样、包序缺口、读错、无效样本及 STOP 尾差均为零。长测失败退一档。三路留作 HPM 专项复测。其余性能项目固定主测档做短窗，专项明确要求长窗时按专项执行。CLI 调用工作台页面时计入 Web 路径。

- **J-Scope 的 Web 与原生路径**各跑满 60 秒。Web 使用真实控件，原生 EP83 通过 `--native-scope --probe-serial` 启用，启动前确认 Web 已释放探针。缺少原生窗口时相关用例仍待验。
- **单路与八路沿用同板历史数据布局**。F103ZE／H743 用 ELF 的 `g_pack` 定位，单路取第六个 DWORD，八路取从基址开始的八个对齐 DWORD。HPM6800EVK 从 `g_v` 定位并保持历史变量类型。八路每组 32 B。
- **实际周期以探针回读为准**：请求周期（µs）换算成 tick 后，必须与探针 METRICS 回读的 `periodTicks` 一致；不一致按失败记，实际值另开行。
- **J02 的 STOP 计数缺一不判通过**：`produced>0`、STOP 尾差 0、USB 丢样 0、读错 0、DAP 让路 0、无效样本 0、包序缺口 0，且尾差与整组计数必须来自同一窗口；缺字段记「不支持/缺口」。
- **J05 用同一窗口的两份导出**。页面保存原始 JSP 和 CSV 后逐值对账。高速长窗样本超过 50 万时另做两秒导出窗口，同时保留 J02/J03/J04 的完整长窗原始文件。
- **不借用别人的速度当门槛。** 某板某链路没有已批准下限时，该性能项结论写「基线已测，待定标」，不得拿其他探针、其他板卡或其他条件的实测值充当本机门槛。目前只有 F103ZE／SWD 的固定文本转发有批准下限（45 MHz ≥2.0 MB/s、60 MHz ≥2.5 MB/s，见 `web/tools/selftest/hw-campaign.mjs` 口径），其余组合一律待定标。
- **SRAM 流水线（H743/SWD）**使用 4 KiB AXI SRAM 窗口，要求 CPU480／HCLK240、核已停机且 D-cache 关闭。按 CMSIS-DAP 回报计算包内字数和队列深度。当前 1024 B × 4 的探针对应 128 字／4 深度，64 块一轮，测三轮并交替读写至少 10 秒。较小的包每轮至少覆盖整个窗口。每包显式设置 TAR，验证回包和载荷。释放 Bulk 后由 OpenOCD 独立读回，再恢复原值、前后哨兵和应用心跳。同探针、链路、包能力和计时条件的历史值下降超过 2% 时复跑并保留两轮。当前等待建立 SuperLinkPRO 流水基线。
- **J-Scope 组率**一律按实际 tick 计算理论组率，短窗下限取 99%，跳拍率与 USB 丢样分别判定；`组/s` 与 `S/s` 不能混用。

## 跨页与断线压力

整板验收时每条工作台链路做三轮。每轮在同一 Web 会话用不同随机顺序运行 RTT Viewer、RTT 转发、J-Scope 和调试。启动后分别核对序号、新采样数据或停点 PC，然后轮换正常切页、空闲断开、工作中断开及工作中拔插 USB 数据线四种结束方式。物理拔插需要能保持目标供电，并记录探针序列号和重枚举后的 COM；条件不足时记待验。

重连后先重跑中断前的业务，核对旧包、资源占用、运行或暂停状态及临时断点。正常停止的转发与 J-Scope 仍需对账 STOP。报告保留每轮顺序、随机种子、结束方式、重连用时和恢复证据。runner 自动执行切页和断开步骤。物理拔插在 `--allow-manual` 下记取证结果。

## 执行入口

默认只出计划，**绝不打开设备**；确认条件后才 `--execute`。

```powershell
# 计划（离线）：打印摘要，并在 --out 下写 plan.json / plan.md
python -X utf8 toolbox.py --out tmp/plan-f103ze board-acceptance --board f103ze

# 只看某一组、某条工作台链路
python -X utf8 toolbox.py board-acceptance --board h743 --link swd --group J

# 硬件执行：必须 --execute，且 --out 是新目录、--runtime 指向已打开执行页的运行时
python -X utf8 toolbox.py --runtime E:/superlinkPRO/tmp/session-NEW --out tmp/run-f103ze-swd `
  board-acceptance --board f103ze --link swd --execute

# 烧录组与人工取证要显式授权
python -X utf8 toolbox.py --runtime E:/superlinkPRO/tmp/session-NEW --out tmp/run-f103ze-flash `
  board-acceptance --board f103ze --link swd --group F --execute --allow-flash --allow-manual

# 离线复核：只读已完成证据目录，按种子逐字重算计划
python -X utf8 toolbox.py --out tmp/review board-acceptance --review tmp/run-f103ze-swd

# J-Scope 组另跑原生 EP83 定速窗
python -X utf8 tools/run_board_acceptance.py --board f103ze --link swd --group J `
  --runtime E:/superlinkPRO/tmp/session-NEW --out tmp/run-f103ze-jscope `
  --execute --native-scope --probe-serial "$ProbeSerial"
```

等价入口：`python -X utf8 tools/run_board_acceptance.py <同上参数>`。

退出码：`0` 通过、`1` 有失败或阻塞、`2` 仍有待验。`--execute` 额外要求：`python -O` 直接拒绝（验收依赖断言）、`--out` 必须是新目录（证据不可覆盖）、`--runtime` 必须存在。

**计划或任务 ACK 不等于成功。** 计划投递成功、队列 `ok:true`、`ack` 释放任务槽、`click` 投递事件，都只是"请求被受理"。结论只能来自 `--execute` 写下的证据和 `--review` 的复核：复核要求会话已完成、源码干净、计划与种子重算逐字一致、通过行的夹具指纹匹配；不满足即拒绝复核。

## 结论判定

- 状态取值：`pass`／`fail`／`blocked`／`pending`／`manual`／`unsupported`／`not-applicable`。实际达到条件但违反门槛记 `fail`；条件建立不起来记 `blocked`；计划内尚未执行记 `pending`；需要人工/量测取证而未授权记 `manual`；产品声明范围外记 `not-applicable` 并写明依据。
- 写入或恢复无法确认时，runner 立即锁定（`Unsafe` 锁存），其余实例记 `blocked`，不会假装恢复成功。
- 人工取证（物理拔插、示波器读数、LA 滤波回读、肉眼颜色）必须先授权 `--allow-manual`，事件写入 `events.jsonl`；未授权时该实例记 `pending`，不能算通过。
- 同一实例多条证据分别判定；一台板一份证据目录，换板新建目录。

## 恢复与清理

按本轮实际改动的对象逐项核对 Flash 备份与回读 SHA、RAM 测试区与哨兵、核心寄存器/FPB/触发器、探针传输模式与档位、目标时钟、串口与 LA 租约、页面任务与队列回收。F05 通过烧录器写回需要恢复的原始扇区，独立核对后确认原应用运行。恢复未确认时保留 `flash-backup.bin`／`backup.bin` 和任务结果，停止后续操作。
