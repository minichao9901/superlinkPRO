# 当前板上固件的匹配版本

此目录重建第一轮实际烧录的 H7B0 ETM 固件，保留该版 TPIU 初始化顺序。
2026-10-11 经 SWD 回读，`fw.bin` 的全部 7672 字节与板上 Flash 一致；`fw.elf` 为网页默认配套 ELF。

HAL 开启完整断言，其 `__FILE__` 字符串影响 Flash 内容。`build.ps1` 使用宏路径映射保留原始编译路径字符串，而 DWARF 指向本目录保留的源代码。
仅作为现有采集和板上程序的准确配套参考。改用另一版本后应使用该版本的 ELF。

详细说明见 [网页初版](../../docs/网页初版.md)。
