## 本轮交付

### 左侧按责任分组

| Tab | 内容与责任 |
|---|---|
| 调试 | 同一 SWD 会话控制当前目标：连接、复位至函数、暂停、继续；ELF 可执行函数搜索与一次性 FPB 断点 |
| 采集 | 上位机配置 ETM、已验收的 4 位并行 TPIU/路由与引脚、LA 参数，以及联动开始/停止 |
| 时钟 | 用户填写 HSE、预期 CPU/TRACECLK；RCC 回读另列。给出公式、分频计算示例和样点数，固件负责 PLL/供电/总线/外设时钟 |
| 文件 | 匹配 ELF/源码、固件指纹、记录导入、单独解码、原始记录包及分析导出 |

采集按钮位于固定底部，不随 Tab 或说明文本被挤出视野。右侧紧凑状态条显示主要计数与质量异常；完整性报告按需展开。执行流与源码占主要区域，可拖动分隔线或用左右键调整比例。窄屏使用“源码/轨迹”切换，历史调用栈可收起。

HSE 输入不会写入 MCU。修改板级输入会按已回读 RCC 重新计算；修改预期值或 LA 采样率不会清除实际回读。计算示例明确使用 VCO=560 MHz、CDCPRE=1，不把任意小数 P/R 当作可直接应用的固件配置。

### 历史执行流

- 上一/下一指令、源码位置、调用、返回、异常、未知/边界；按历史序号或 0xPC 定位。
- PC 多次出现时定位后续匹配，到末尾再回到首个匹配；定位自动打开对应页并滚动到选中行。
- 选中位置联动机器码、源码和历史调用路径；未知祖先保持灰色。边界/异常事件没有可证实栈时明确显示不可用。
- 历史导航不单步当前目标，不把当前寄存器值用于历史状态判定。
- 原始汇总、详细事件和源码分别查询。已有包/调用/火焰图/热点视图保留，火焰图仍按路径记录数计数，不是耗时图。

### 长记录与证据检查

新增 `tools/record_store.py`，在工作记录目录生成可重建的 `browse-v3.sqlite`。原始 CSV/KVDAT、ELF、解码 JSON 和封存文件不改写。

接口以 `/api/browse/<id>/` 为前缀：`overview`、`page`、`event/<seq>`、`source`、`navigate`、`issues`。旧完整结果及导入导出接口继续保留。

10 ms 基准首次建立索引约需 15 秒；最终实测索引复用时，汇总加 150 条事件的本地 API 请求（包括打开记录时的指纹核对）共约 49 毫秒，响应分别为 39,396 / 74,882 字节，避免浏览时反复下载 272 MB JSON。这是本机一次测量，不作为性能保证；记录在 `validation/2026-10-11-v3-browse.json`。

当前索引缓存仍较大（10 ms 约 442 MB），首次建设仍会读取完整 JSON；尚未完成解码时的流式写入或数据去重。进一步扩窗口前应继续优化这一层，现有解码器的 200 万展开记录上限仍保留，不输出静默截断结果。

原始输入、ELF 或配置与解码指纹不一致时拒绝把旧结果作为当前历史。索引根据解码及关联文件变化重建。输入长度与实际处理长度分别核算；未处理输入、包覆盖缺口/重叠、overflow/坏包、未知条件、失同步与物理边界分别显示。字节缺口不凭空对应到某条故障指令。

采集/解码失败原因保存到 `session.json`。重开未解码记录会显示原因，清空旧源码/栈，保留原始证据。CLI 导出文件未落地的错误改为可被采集服务处理的异常，避免任务线程退出后仍停留在“保存中”。

## 函数断点起点采集

载入 ELF → 搜索初始化后的函数 → 运行至函数并暂停 → 移除本次一次性比较器 → 保持 PC 未执行 → 配置 ETM/TPIU → LA 等待触发 → 继续 CPU → 保存与解码 → 恢复原 trace 设置。

默认“采集前停在选定函数”和“先复位”都勾选，以便只执行一次的 `spi_trace_ready` 每次都能命中。反复调用的函数也可取消“先复位”，直接等下一次调用。起点比较器在继续前移除，不用提前单步跨过它，首条待采指令不会被消费。

符号取自匹配 ELF 的可执行函数表，FPB 编码复用主调试页 `app/dbg/bp.js`；没有接入另一套会清空断点的调试会话。容量不足、命中地址不符、超时和取消会报错并清理本次槽位。其他比较器不覆盖；若 FPB 原本关闭却保留其他启用比较器，拒绝贸然启用它们。

本版是**函数入口一次性硬件断点**，不是完整 GDB 服务端，也未实现长期断点自动重装、源级单步或变量面板。`Reset_Handler`、`SystemInit`、`SystemClock_Config`、`main` 等初始化入口仍禁用；本版 ELF 验收限定内部 Flash 执行代码。先核对实际 CPU/TRACECLK，再配置并采集，网页不自行修正固件主频。
