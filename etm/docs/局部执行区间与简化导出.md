# 局部执行区间、简化导出与单一源码入口

2026-10-11，按用户确认的三项界面改进完成。此次不操作 SWD/LA，不改固件或频率。

## J-Trace / Ozone 对照

Ozone 的 Timeline 按时间显示调用栈，指令光标与指令/源码窗口联动。官方手册 4.22.2 说明鼠标拖动平移、Ctrl＋滚轮横向缩放。它与按调用权重排列的聚合火焰图是不同概念。

参考：[Ozone 用户手册](https://www.segger.com/downloads/jlink/UM08025_Ozone.pdf)、[官方 trace 功能说明](https://www.segger.com/products/development-tools/ozone-j-link-debugger/technology/trace-features/)。

当前记录的 timeBasis 为 execution order，无已验收的逐指令时间戳。此次明确使用执行序号，不将总采集时长按指令数均分，也不把 trace 包传输时间当作 CPU 指令执行时间。真正的 µs/ms 区间仍需后续验收 ETM 时间戳/周期计数及其解码关联；旧记录不能补造缺失时间。

## 执行流函数轨迹

- 执行流页的指令表与源码窗格上方新增函数泳道图，可独立收起。
- 横轴标注 ETM 解码序号。图中显示记录最多的 6 个函数、其他函数、状态未知、未成立路径，并以竖线标出同步/缺口和中断事件。
- 每个泳道将当前区间聚合为最多 1,600 个显示列，便于快速查看长记录中的活动分布；图上拖选会把精确序号范围联动到执行流、源码、区间统计和支持区间的导出。点击或用左右键按序号定位指令和源码。搜索及“隐藏未成立分支”筛选会同步作用于图表。
- 泳道密度不表示函数耗时或真实墙钟时间；被聚合的像素列也不代表单条指令。若需要微秒/毫秒坐标，仍须先验收逐指令时间信息。

## 局部执行段

- 火焰图页提供“按执行顺序”和“按调用权重”两种视图，默认先显示调用区间的执行先后关系。
- 执行顺序图支持横向拖选、Ctrl＋滚轮缩放、执行序号输入、返回上一级、完整区间重置。
- 函数泳道和火焰图工具栏提供放大、缩小与适配全区间按钮；放大/缩小以当前序号光标为中心，保留光标并联动下方记录和源码。执行顺序火焰图显示竖直光标；调用权重图横轴是调用记录量，因此用描边标出光标所属函数。
- 点击区间位置定位对应历史指令和源码；不单步或操作目标 CPU。
- 选区联动执行流、调用统计、热点和火焰权重；简化 C/HTML、完整源码流和 CSV 导出携带同一执行序号范围。
- 原始包、完整性核算与原始记录包仍是全记录，界面明确标识其范围。
- 局部火焰权重使用全记录中已经重建的 callPath，不从截取点重新猜测祖先。进入窗口之前已经发生的调用不计作窗口内新调用。
- 大范围以有限数量的显示桶保留总覆盖；一个桶包含多种栈路径时，仅显示共同祖先与灰色“多段调用（放大查看）”，事件有标记。放大后提高分辨率，不把多个调用冒充一个精确调用区间。
- 执行顺序图按当前区间可恢复的最大 `callPath` 深度动态生成高度，没有固定层数上限；层数多时可在图内纵向滚动。混合显示桶里的更深分支需放大区间后分别查看。

## 火焰图页面板

火焰图页使用上下布局：执行顺序/调用权重图占上方全宽，当前源码和指令说明放在下方；“收起源码”可让图表占满分析区，再次展开会保留当前源码定位。隐藏无内容的分页条。执行流和其它分析页继续使用原有分栏布局。图表坐标系扩展到全宽，保持函数标签和泳道高度适合阅读。

## 简化 C

- 不再在每条源码前重复函数名、绝对路径和行号。
- 文件绝对路径只在开头列出一次；函数/文件切换时保留短段落注释。
- 连续相同源码位置继续合并，非连续回跳和循环顺序保留。
- 未确证条件、源码缺失、中断和同步边界仍有必要标记。
- 完整源码导出保留原有逐指令/位置说明，精细序号和 PC 还可从 CSV/JSON 核对。

用户记录 `capture-9111c4d38fc9439299ba1d66d53e29c6` 共 93,672 条路径。新简化 C 有 20,894 条源码片段和 2,494 条注释（包括未知/边界及函数切换），输出 1,326,170 字节。路径注释不再逐行重复。

示例：`validation/2026-10-11-simplified-blocks.c`。

## 简化 HTML

- 新增独立单文件导出“简化执行流 / 源码 .html”。
- 左栏是按恢复顺序排列的简化源码片段，右栏是原始源文件；选择片段后在右栏定位源码行。
- 序号范围、首 PC、函数、文件/行和合并记录数放在信息栏，不插进每行源码。
- 支持分页、搜索和按执行序号定位；未成立条件不作为已执行源码输出，未知行有独立状态。
- 源码、数据、样式、脚本全部内嵌，无 CDN 或外部脚本。源码 HTML 特殊字符在 JSON 嵌入时转义，展示时用 textContent，避免源码被当作脚本执行。

浏览器实际导出 `#20213～#56167`，生成 3,139,475 字节的单文件：`validation/2026-10-11-simplified-window.html`。

脚本语法与嵌入数据校验通过，测试覆盖源码脚本标签转义及导出区间。应用内浏览器工具安全策略禁止访问 file://，因此未自动完成离线文件的双栏点击验收；需要用户用本机浏览器打开该文件验证。

## SourceStore 单一入口

界面仅保留“选择源码目录…”。仍复用主工具 SourceStore：原生目录授权可用时调用 pick；不可用时，同一个按钮使用 FileList 兼容路径。原生授权因环境限制失败时提示再次点击切换兼容方式，取消选择不会触发兼容读取。底层兼容性保留，不再展示两个模式按钮。
