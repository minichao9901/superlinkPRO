# 界面细节收紧

2026-10-11，按用户三张截图调整。

- 区间的“起点、终点、查看”组合成不拆行的整体；视图切换/上一级/重置也作为独立组。收紧字号和间距，默认左右分栏宽度下保持一行；更窄时可整组换行，输入和标签不再分散。
- 顶部记录选择限制合理宽度，与路径统计、质量摘要和报告按钮合并为一行。完整质量说明保留在悬停提示和报告中，较窄时省略显示。
- 默认仅显示一个封存验收 Demo（70/35 MHz、1 ms）以及用户自己的采集/导入记录。
- 早期实验、失败频率档、旧示例不再挤在默认列表；文件页“显示实验历史记录”可查看全部。数据仍在原位置，当前打开的历史记录不会因关掉此开关而丢失选择。
- 新采集/导入标记用户记录；内部验收脚本标记验证记录。旧记录按已有采集元数据分类，不改写其 session.json 或封存资产。

验证：12 项服务端测试通过。浏览器默认列表为一个 Demo 和两条用户记录；打开实验历史后共有 42 个选项（包括占位项）。在区间工具可用宽度 469 px 下，两输入框的 top 均为 150.05 px，工具栏高 24.1 px，没有区间拆行或页面横向溢出。合并后的顶栏高约 31.2 px。
