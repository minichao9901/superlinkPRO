# 断点流程与芯片预置第四版

2026-10-11。继续保持 H7B0 CPU 70 MHz / TRACECLK 35 MHz；未烧录、未调整频率，未集成主工具。

## 实际操作顺序

Tab 与页内顺序均按一次录制安排：

1. **调试**：浏览载入目标 ELF（可同时选择源码目录）→ 自动识别/选择芯片预置并连接探针 → 在函数前点击“＋”或输入断点命令 → 在断点列表用圆点选择采集起点。
2. **时钟**：填写板上实际 HSE → 回读 RCC → 核对 CPU、HCLK、TRACECLK。默认自动使用回读结果填入预期值，也可关闭自动填入后手动核对。
3. **采集**：设置 ETM/TPIU → 检查 Kingst 连接与采样参数 → 联动采集。默认先复位到所选断点，配置 trace，等待 LA 就绪，再继续 CPU。通常无需提前点击“运行至起点”或“配置并暂停”。
4. **文件**：导入、单独解码、保存记录包和导出；操作日志按需展开。

需要手工停到起点时，使用“运行至起点”或“复位至起点”。如果随后从当前 PC 采集，取消“联动采集前停在所选断点”，避免再次复位。

## 断点行为

- 函数前“＋”添加断点；已添加显示“●”。函数搜索不再清掉已选起点。
- 命令支持 `b HAL_SPI_Transmit`、`b main:255`、`b main.c:255`、`b *0x08003c1c`，可按回车添加。
- `main:255` 表示 main 所在源文件的绝对第 255 行。没有 DWARF、没有符号或该行没有可确认的机器码时明确报错；不替换成附近行。一行对应多个地址时显示候选供选择。
- 当前基准 ELF 的第 199 行没有对应机器码，所以 `b main:199` 应明确失败；不是该命令格式不支持。已实测第 255 行对应 `0x08000894`。
- 列表支持启用、禁用、删除、清空和选采集起点；状态区分“待下发”“已生效”“已命中”“已禁用”。未连接可先添加，连接并通过目标 Flash/ELF 校验后下发。
- 使用实际 FPB 硬件断点，回读槽位容量，只租用空闲槽位，不改写 Flash、不清掉其他工具的比较器。
- 从已命中的本页断点继续时，临时摘掉该比较器，执行一次硬件单步，再恢复。单步失败则保持暂停，明确报错；无论成功失败都清理 C_MASKINTS。
- 起点定位及采集期间暂时停用本页断点；完成或失败后恢复原先已生效的断点。校验失败的待下发项不会在清理阶段被意外启用。
- 复位/运行至起点使用一次性比较器，命中后移除，首条待采指令不会在 LA 启动之前执行。采集结束后刷新目标状态，恢复本页断点可能让 CPU 再次命中暂停，界面如实显示。
- 启动入口断点可用于调试；Reset_Handler/SystemInit/SystemClock_Config/main 的函数入口仍不能默认作为已验收的 trace 起点。

## 预置范围与自动识别

沿用主工具 SWO 的预置范围，按 CPUID 与 DBGMCU DEV_ID 一起匹配。选择错误预置会拒绝继续，不会使用其他系列寄存器地址。

| 预置 | DEV_ID | 型号/时钟/断点 | 完整 trace 配置与解码 |
|---|---|---|---|
| STM32F103 对应的标准/高/超大容量组 | 0x410 / 0x414 / 0x430 | 已加入；当前无 F1 真机验收 | 未适配，不能沿用 ETMv4 |
| STM32F405/F407 对应组 | 0x413 | 已加入；当前无 F4 真机验收 | ETMv3.5，仍需专用配置/解码适配 |
| STM32H742/H743/H750/H753 对应组 | 0x450 | 已加入；当前无该组真机验收 | ETMv4，但路由/引脚/控制仍需适配和实测 |
| STM32H7B0/H7A3/H7B3 对应组 | 0x480 | H7B0 已实测 | 保留原适配；H7B0 70/35 MHz 业务窗口已验收，其他同组型号需实测 |

这些是具体型号组的预置，不代表 F1/F4/H7 全部子型号已经支持。DEV_ID 标识型号组，不能据此判断完整料号、封装或板上已引出的 trace 引脚。

RCC 信息按型号读取两次，变化时不输出混合快照频率。读取实际 PLL、分频、时钟源、CPU/HCLK；并行 DDR 的物理 TRACECLK 按 TRACEPORTCK/2 推算。内部时钟使用标称值；外部晶振/有源时钟必须用户提供。不同型号组切换不沿用 H7B0 的 25 MHz。页面不会写 PLL 或供电配置。

F1/F4 同时回读 DBGMCU trace 引脚使能/模式；H7B0 保留 ETM IDR、CONFIGR、Trace ID、TPIU 宽度回读。尚未适配的芯片不会调用 H7B0 的 ETM/Funnel/ETF/TPIU 写寄存器路径。

目标 ELF 载入范围扩大到 STM32 内部 Flash，便于不同芯片进行断点操作；当前联动 trace 仍限制为已经验收的 H7B0 内部 128 KiB 执行镜像。RAM/外部存储执行不在当前范围。

参考：[Arm ETM-M4 技术手册（ETMv3.5）](https://documentation-service.arm.com/static/5e8ecc36c5ee7d4a00693f2f)、[STM32F4 RM0090](https://www.st.com/resource/en/reference_manual/rm0090-stm32f407-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)、[STM32F103 高容量数据手册](https://www.st.com/resource/en/datasheet/stm32f103ve.pdf)。
