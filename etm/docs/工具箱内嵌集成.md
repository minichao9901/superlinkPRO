# 工具箱内嵌集成

2026-10-14，为 `web-serial-rtt-tools` 的更多功能提供同源内嵌能力，基于主线 `9dfb670`，不引入PXLogic实验分支。

独立 `start-web.ps1` 和根 `/api/` 路径保持可用。工具箱本地服务将ETM挂到 `/etm/`，页面通过 `data-api-base` 使用 `/etm/api/`；ELF下载地址使用真实挂载前缀。

内嵌页面注入主工具的WebUSB驱动和ProbeManager操作入口，关闭子页面独立BroadcastChannel，避免自己释放自己或嵌套锁等待。目标操作、连接、断点变更和联动采集走统一仲裁；停止与取消信号可立即送出，历史读取不占用目标资源。独立页面不注入host时继续使用自己的驱动和ProbeBus。

完整使用说明位于工具箱仓库的 `docs/etm-integration.md`。本次实板同源接口验收：F103ZE 48/24 MHz，Kingst500 MSa/s、10 ms、2.0 V，相位0.25、分支广播关闭；三轮解码174786/174785/174786条指令，overflow与包错误均为0，源码映射完整。停止时CPU保持暂停，结束后允许管理器释放并重新连接。

证据：本次Codex worktree的 `tmp/serial-integration-hw.json` 及其列出的记录；发布时复制到协调目录 `artifacts/20261014-serial-etm-integration`。原始失败的CH4缺失记录保留，不改写证据。浏览器菜单/历史分析另行检查；自动化没有完成实际WebUSB设备授权与物理USB接口转交，不能把持续SWD接口验收解释为完整浏览器USB验收。
