# 第三版界面压缩与 ELF 流程调整

2026-10-11，按用户三张截图调整。

## 高度分配

- 顶栏从 54 px 缩为 38 px，移除重复的记录标题行。
- 将历史导航、定位、搜索和筛选合并到一行；完整质量说明保留在提示与报告中。
- 历史调用栈改为紧凑横条，操作日志移到文件 Tab 按需展开。
- 解码/源码区域占剩余高度，可调整左右比例。

最终浏览器视口实测为 1242×668：主面板高 495 px，调用栈横条高 19 px，页面无横向溢出。控件的文字大小仍保留可读性，主要通过合并与减少间距释放高度。

## ELF 操作流程

- 移除预置固件下拉、预置 ELF 下载和示例快捷按钮；启动时不自动载入固件、函数或记录。
- “浏览载入 ELF”位于调试 Tab：SWD 控制区之后、函数断点区之前。
- 载入文件后解析符号，但不自动选择函数。用户手动选择采集起点，再运行至函数或联动采集。
- 默认函数起点联动流程中，未载入 ELF/未选择起点/未连接探针时，相关 trace 操作不能提前启动。
- 打开历史记录不会替换目标调试 ELF；记录包仍保留自身的 ELF 和源码。
- 文件 Tab 保留源码目录、记录导入、单独解码、导出与日志。

本次“通用”调整针对文件载入与操作流程；现有 H7B0、内部 Flash、初始化后业务入口的硬件验收范围没有扩大。

## 验证

实际通过浏览器文件选择器载入 ELF，解析出 233 个函数；载入后保持起点未选，选择 `HAL_SPI_Transmit` 后显示地址 `0x08003c1c`。打开 10 ms 历史记录不会自动填入 ELF，也不会改变用户已选的目标 ELF/函数。

原有 41 项 Python、8 项 JavaScript 测试通过。本次未烧录或操作目标硬件。
