# 70 MHz CPU / 35 MHz TRACECLK 稳定基准 v1

2026-10-11：本档重新烧录并完成 1 ms 复验及 10 ms 全地址业务窗口验收。按用户要求，固定本版本，暂停频率优化；没有安排自动高频测试。目标板结束时运行正常，trace 设置已恢复，原生 SWD 验收连接已释放。

## 固定参数

- STM32H7B0，HSE 25 MHz，LDO；CPU 70 MHz，HCLK 35 MHz，物理 TRACECLK 35 MHz。
- 4 位 DDR，70 M 次半周期传输/秒；Kingst MIPI16，500 MSa/s，阈值 1.65 V。
- CH0=PE2，CH1～4=PE3～PE6；GPIO 驱动速度 3，半周期取样位置 0.25。
- KVDAT 快照确认 CH0～4 启用 1 采样点毛刺滤波（2 ns）；其他通道关闭。保留模式为下次启动清除，重启 KingstVIS 后必须再核对。
- ETMv4，Trace ID 2，CONFIGR=1；返回栈压缩、周期计数、数据 trace 关闭。业务窗口不按地址过滤。
- SPI2 内核 200 MHz，SPI 分频 /4；保留原例程每次轮询发送 100 字节、PC8 标记和 SysTick。

固件封存在 `../../firmware/stm32h7b0_spi_trace/stable-70-35-v1/fw.elf`，BIN/HEX 同目录。目标 Flash 全部 19,876 字节逐字节匹配，BIN SHA256：`4275f9b8873aa602da8e5bf7e7acede3884d2b22fa510f3784dfec5d8e94dad2`。网页“SPI · 70 MHz CPU / 35 MHz trace · 稳定基准 v1”绑定这份封存 ELF；重新构建的 `fw-70.*` 不会覆盖封存文件。

两份采集在 0.10、0.20、0.25、0.30、0.40 位置均得到各自完全相同的 ETM 字节流。10 ms 所选稳定窗宽约 4.2 ns，0.25 的最小数字数据跳变距离约 2.5 ns。靠近数据转换区的 0.50～0.70 校验失败；不能任意移动取样位置。

10 ms 记录尾部包含一次未闭合发送，已看到 3 次 TXDR 字节写入，不计作完整发送；保留 2 字节同步前数据和 14 字节未完成尾帧。初始化/捕获边界不补造执行历史。

这里的“全量”是**该业务采集窗口内全部地址的指令 trace**，不表示包含上电启动全过程、无限运行历史、任意程序都绝不溢出或所有变量值。397 条 IT 条件指令的执行状态仍为未知，源码执行流会明确标注。因此该版本通过当前业务窗口的包、分支和发送结构验收，尚不能宣称每条指令都得到完全确定的执行判定。

## 保存的文件

- `capture-10ms.etmrecord`：原始 CSV、Kingst 档案、匹配 ELF、源码、采集和滤波设置；可在网页导入后重新解码。
- `decoded.json.gz`：完整解码结果的压缩备份。
- `execution.c`、`execution-simplified.c`：由 10 ms 记录导出的完整与简化源码流。两个大型文本文件不纳入 Git；其字节数和 SHA256 仍保存在 `manifest.json` 中供原工作区核对。
- `validation.json`：包覆盖、实际分支/发送核对、相位扫描、硬件与滤波快照。
- `manifest.json`：固件、记录 ID、参数及基准产物的 SHA256；不同内容拒绝覆盖。

需要重建源码流时，在网页导入 `capture-10ms.etmrecord` 并单独解码，再从“文件”页导出完整源码或简化 C。Git 保存压缩记录和解码 JSON，不保存约 110 MB 的源码导出文件。

本机原始工作记录：10 ms 为 `../../records/capture-8365b3adb65b4f0cb281e55aef2c89c7/`，1 ms 为 `../../records/capture-926a4f2b899542f5b566e68a1d1eb631/`。`records/` 属于本地运行数据，不纳入 Git。

## 网页与后续操作

打开 http://127.0.0.1:8766 。本机保留 `records/` 时可从列表打开 1 ms 复验预览；在干净副本中导入 `capture-10ms.etmrecord` 查看封存记录。历史记录使用各自保存的 ELF 与源码快照。执行顺序、调用统计、火焰图、热点和完整性视图均使用同一记录。火焰图仍按指令路径数量加权，不等于耗时。

下次采集保持 70/35 档和上述参数，在业务入口复位后联动采集。使用 `tools/flash_spi.py 70` 时优先烧录封存 BIN。执行 `tools/freeze-spi-70.mjs` 仅会采集本档，不进行频率扫描；需要本地 SWD 验收适配服务。`package_spi_baseline.py` 拒绝用不同内容覆盖 v1，后续更新应建立新版本。

软件验证：31 项 Python 测试和 3 项 JavaScript 测试通过；包含封存记录优先于新实验记录、滤波快照真实采样率校验、配置恢复和 FIFO 顺序检查。
